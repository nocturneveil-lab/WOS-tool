# Alliance Map

`default-layout.json` is loaded automatically when the page opens and the browser has no saved map layout. Keep it in the same published directory as `index.html`.

To update the published default, export a layout with the page's **ファイルに保存** button and replace `default-layout.json` with that JSON file. Visitors who already have a layout saved in their browser keep using their own saved layout.

Exported JSON, map, table, and PDF filenames include the local save date and time to the minute (`YYYY-MM-DD_HH-mm`).
