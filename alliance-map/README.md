# Alliance Map

マップは Firebase（Cloud Firestore）に保存され、開いている全員の画面にリアルタイムで反映されます。
**マップを更新するために JSON を差し替えて push する必要はありません。** 保存可能アカウントで編集すると、自動でWebに保存されます。

## 権限

| 権限 | ログイン | できること |
|---|---|---|
| 閲覧 | なし（URLを開くだけ） | 表示、ズーム、パン、画像（PNG/SVG）出力。Webの最新状態がリアルタイムで反映される |
| 編集 | 合言葉のみ | すべての編集操作。ただし**変更はそのブラウザ内だけ**で、Webには保存されない。［最新に戻す］でWebの状態に戻せる。履歴の閲覧とプレビュー |
| 保存可 | アカウント名＋合言葉 | 編集内容をWebへ自動保存。履歴からの復元、名前付き保存、共有設定（色・MAPサイズ・熊罠の文字サイズ・初期表示）の保存、JSONのバックアップと読み込み |

- 保存可で編集すると、最後の変更から約1秒後に自動保存されます。ヘッダー右側に「保存済み」「保存中…」「保存失敗（押して再試行）」「オフライン」と表示されます（狭い画面ではアイコン＋「保存済」などの短い表示）。
- ヘッダー右端のボタンが、ログイン状態（閲覧・編集・保存可のアカウント名）の表示を兼ねています。閲覧のときに押すとログイン、ログイン中に押すとログアウトです。
- 文字サイズ・ファイル保存・読み込み・画像出力・SVG出力・設定・リセット・履歴は、ヘッダーの「⋯」メニューにあります。
- 他の人とほぼ同時に保存した場合は、後から保存した側の内容になります。上書きされた内容は履歴（編集開始前）から復元できます。
- 初期表示（開いたときの中心とズーム）は、保存可が「⋯」→「設定」→「現在の表示を初期表示にする」で変更します。ほかの人の表示位置が勝手に動くことはありません。
- ログイン状態はブラウザに保持されます。合言葉は保存されません（保存可のアカウント名だけ記憶します）。

## 履歴

「⋯」メニューの「履歴」（編集・保存可）から開きます。

- **編集開始前**：保存可が、しばらく（10分以上）ぶりに変更を保存する直前の状態。
- **復元前**：履歴から復元する直前の状態。
- **リセット前**・**読み込み前**：保存可がリセット、または JSON ファイルの読み込み（Web のマップを丸ごと置き換える操作）をする直前の状態。10分の間隔に関係なく必ず記録されます。
- **名前付き保存（★）**：「現在の状態に名前を付けて保存」で作成。最大20件。自動では削除されません。
- 自動の履歴（名前付き保存以外）は合わせて最新30件だけ残り、古いものから削除されます。
- 履歴を記録できなかった場合は、マップも保存されません（「保存失敗［再試行］」になります）。
- ［プレビュー］は自分の画面にだけ表示されます。［復元］は保存可だけが使え、全員のマップが置き換わります。

## Webに接続できないとき

- Webに接続できない場合や、Webにマップが未登録の場合は、`default-layout.json`（公開用の配置）を表示し、「オフライン表示」と明示します。
- `file://` で開いた場合など Firebase 自体を読み込めない場合は、従来どおり Web 保存なしで全機能（ファイル保存・読み込みを含む）を使えます。Firebase のログインは `file://` では動かないため、動作確認は Live Server などで `http://localhost` から開いてください。
- `default-layout.json` はオフライン表示と初回の登録のために残しています。

## Firebase の設定

プロジェクト：`alliance-map-fbbf6`。設定値は `cloud-shared.js` の先頭にあります（apiKey は公開してよい値です）。

### 初期設定（済みの項目は飛ばしてよい）

1. Authentication で「メール/パスワード」方式を有効にする。
2. Authentication の設定で、新規登録（ユーザーによるアカウント作成）を無効にする。
3. 承認済みドメインに `nocturneveil-lab.github.io` を追加する。
4. Firestore を作成する（ロケーション `asia-northeast1`）。
5. `firestore.rules` の内容をセキュリティルールとして公開する。
6. push 後、保存可としてログインし、帯の「公開用の配置をWebに登録」を押す（`default-layout.json` の内容が Web に登録されます）。

### アカウント管理

アプリの画面にメールアドレスは表示されませんが、内部では Firebase Authentication の「メール/パスワード」を使っています。
どの操作も Firebase コンソールの Authentication →「ユーザー」で行います。

| 操作 | 手順 |
|---|---|
| 編集の合言葉を設定 | 「ユーザーを追加」。メールに `editor@alliance-map.app`、パスワードに合言葉（6文字以上）を入力する |
| 編集の合言葉を変更 | 上記のユーザーを削除し、同じメールアドレスで新しい合言葉を設定して作り直す |
| 保存可能な人を追加 | 「ユーザーを追加」。メールに `{アカウント名}@saver.alliance-map.app`（アカウント名は半角英小文字・数字・`_`・`-` の1〜20文字）、パスワードにその人の合言葉を入力する |
| 保存可能な人を削除 | その人のユーザーを削除する（最大1時間で書き込めなくなる） |
| 保存可能な人の合言葉を変更 | 本人がアプリの「⋯」→「設定」→「自分の合言葉を変更」で変更する。忘れた場合は、管理者がユーザーを削除して同じアカウント名で作り直す |

書き込みの権限は Firestore のセキュリティルール（`firestore.rules`）で強制しています。`@saver.alliance-map.app` のアカウントだけが書き込めるため、保存可能な人を増減してもルールの変更は不要です。

## データの形式

- `maps/main`：現在のマップ。「ファイルに保存」で書き出す JSON と同じ形式に、`updatedAt`・`updatedBy`（アカウント名）・`rev`（保存のたびに +1）を加えたもの。
- `maps/main/history/{id}`：履歴。`kind`（`before-edit` / `before-restore` / `before-reset` / `before-import` / `named`）、`name`（名前付き保存のみ）、`layout`、`createdAt`、`createdBy`。

保存可の「ファイルに保存」で JSON のバックアップを取れます。読み込むと Web のマップが置き換わります（確認が出ます）。
書き出した JSON と画像のファイル名には、保存した日時（`YYYY-MM-DD_HH-mm`）が入ります。

## オブジェクトの種類を追加・変更するときの注意

Web のマップや履歴を読み込むとき、知らない種類のIDが含まれていると「未対応のデータ」として読み込みを拒否します。

- **種類を追加するときは、先にコードを push してから、その種類を配置してください。** 古いコードのままの画面（キャッシュされたページなど）では、新しい種類を含むマップを読み込めません。push 後、全員がページを再読み込みしてから配置するのが安全です。
- **既存の種類のID（`headquarters`・`flag`・`city`・`bearTrap`・`allianceBuilding`・`largeGatheringSite`・`unavailable`）は削除・変更しないでください。** Web のマップや履歴、バックアップの JSON に残っているデータが読み込めなくなります。表示名（`map-core.js` の `TYPE_LABELS`）や色は変更して構いません。

## ファイル構成

ビルドは不要です。ファイルをそのまま push すれば GitHub Pages で動きます。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（HTML）だけ。CSS と下記のスクリプトを読み込む |
| `style.css` | 見た目（ライト／ダーク、狭い画面用の表示、権限による表示の出し分け） |
| `map-core.js` | グリッドの計算、マップの状態（配置・選択中のオブジェクト）、描画、レイアウトの検証と読み書き（`getLayout` / `applyLayout`）、ブラウザに保存する設定、PNG/SVG出力 |
| `map-edit.js` | マップ上の操作：配置・消去・選択・移動、ひとつ戻る、ドラッグ（移動・パン）、ピンチやCtrl+ホイールでのズーム、長押し・右クリックでの名称変更 |
| `map-ui.js` | ツールバー、ツール一覧と「⋯」メニュー、選択中のバー、名前入力・画像プレビュー・設定の各ダイアログ、ファイルの保存・読み込み、リセット |
| `map-app.js` | 権限（閲覧・編集・保存可）の切り替え、`window.AllianceMapApp`（cloud.js との窓口）、起動処理 |
| `cloud.js` | Web 保存の起動処理（Firebase SDK 13.0.0 を gstatic から読み込み、接続して受信・ログインを開始する） |
| `cloud-shared.js` | cloud-*.js の共通部分：Firebase の設定と接続、状態（`state`）、ヘッダーの状態表示・帯・トーストなどの部品、レイアウトの比較用キー |
| `cloud-sync.js` | Web のマップの受信と適用、保存可の自動保存、ヘッダーの保存状態と帯の表示、公開用の配置の登録、初期表示の保存 |
| `cloud-history.js` | 履歴の一覧・プレビュー・復元・名前付き保存 |
| `cloud-auth.js` | ログイン・ログアウト、アカウントからの権限の判定、合言葉の変更 |
| `firestore.rules` | Firestore のセキュリティルール |
| `default-layout.json` | 公開用の配置（オフライン表示・初回の登録用） |

- `map-*.js` は通常のスクリプトで、`map-core.js` → `map-edit.js` → `map-ui.js` → `map-app.js` の順に読み込みます（後のファイルが前のファイルの関数を使うため、順序を変えないでください）。トップレベルの変数・関数はファイル間で共有されます。
- `cloud*.js` は ES モジュールです。`index.html` は `cloud.js` だけを読み込み、残りは `import` で読み込まれます。マップの操作は必ず `window.AllianceMapApp` を通します。
