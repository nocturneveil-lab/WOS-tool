# ホワサバ集結支援ツール

Whiteout Survival（ホワサバ）のSvS・要塞戦などで、複数の集結を同時に着弾させるための指示用ツールです。
スマートフォンでの片手操作を想定しています。

## 使い方

1. 時計をタップして補正を開き、ゲーム内のUTC時刻と合うように ±0.1秒 で調整する（補正値をタップすると0に戻る）
2. 設定欄で「集結時間」「行軍時間（最終ラインからの秒数）」「指示バッファ」「丸め単位」を入力する
3. 再生中は、着弾時刻に「今すぐ立てた場合の最速着弾時刻」が表示され続ける
4. 一時停止を押すと、その時刻を5秒または10秒単位で切り上げて確定する
5. 必要に応じてコメントを入力し（前に置くと改行あり、後ろに置くと半角スペース区切り）、コピーして同盟チャットに貼り付ける
6. 最終ラインを過ぎると赤表示になる。ボタンを押すと再生に戻り、取り直しができる

## 計算式

- 着弾時刻 ＝ 現在UTC（補正込み）＋ 集結時間 ＋ 行軍時間 ＋ 指示バッファ（確定時に切り上げ）
- 最終ライン ＝ 着弾時刻 − 集結時間 − 行軍時間

各メンバーは、ゲーム画面に表示される到着予定時刻が指示された着弾時刻になった瞬間に集結を立てれば、全員が同時に着弾します。

## チャット出力の例

| コメント | 位置 | 出力 |
|---|---|---|
| なし | － | `U39.10` |
| 全軍 | 後ろ | `U39.10 全軍` |
| 全軍 | 前 | `全軍`（改行）`U39.10` |

`U分.秒` の形式です（時は省略）。

## 動作環境

- 1ファイル（`index.html`）だけで動作します。インストールは不要です
- コピー機能はHTTPSで開いたときに確実に動作します（GitHub Pagesは対応済み）
- 設定は端末のブラウザに保存されます
