# 2863王国 憲章（Whiteout Survival #2863）

2863王国の約束・イベント・同盟をまとめた1ページのWebサイトです。
内容はGoogleスプレッドシートで管理し、Google Apps Script（GAS）経由で読み込んでいます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（デザイン・表示処理。CSSは事前ビルド済み） |
| `gas/Code.gs` | スプレッドシートを読み込んでJSONを返すGAS（GASエディタに貼り付けて使用） |

## 内容の更新

文章・ルール・フォーム・同盟情報の変更は、**スプレッドシートを編集するだけ**です。
このリポジトリのファイルを触る必要はありません。

- シートは「表紙 / サーバーの約束 / イベントガイド / 同盟紹介」の4枚（ページの上から順）
- 行の順番がそのまま表示順、「非表示」にすると行を消さずに隠せる
- 編集後、反映まで最大1分（GASのキャッシュ）。すぐ反映したい場合はGASで `clearCache` を実行

## GASの更新

1. `gas/Code.gs` の内容をGASエディタに貼り付けて保存
2. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→ デプロイ
   （既存のデプロイを編集すればURLは変わりません）
